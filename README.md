# 🏢 Engineering College — Electrical Drawing & CAD Documentation

## Project Overview

This repository contains the **AutoCAD DWG source file and PDF documentation** for the electrical drawing package of a proposed **10-storied Academic Building (Civil Engineering)**.

The project was prepared under the **Education Engineering Department, Ministry of Education**, as part of the proposed establishment of four Engineering Colleges in the Chattogram, Khulna, Rajshahi, and Rangpur Divisions.

## 👤 My Role

**Role: Draftsman**

I was responsible for the **CAD drafting and preparation of the electrical drawing documentation** for this project.

My work included preparing and organizing the electrical fixture layout drawings and associated CAD documentation across the building's different floors.

The project drawing title block officially identifies **Jubayer Azad Jim** as the **Draftsman**.

## 📐 Drawing Documentation

The drawing package includes:

* Floor-wise electrical fixture layout plans
* Lighting and power layouts
* Electrical distribution board layouts
* Electrical fixture schedules
* Fire alarm and heat detector locations
* Lightning protection and earthing arrangements
* Electrical fitting mounting heights
* Cable and conduit schedules
* Distribution and circuit information
* General electrical installation notes

The documentation covers multiple floors of the proposed academic building with dedicated electrical layouts and distribution arrangements.

## 📊 Electrical Documentation

The drawing package contains electrical distribution information including **PSDB, LSDB, SSDB and ESDB**, together with circuit arrangements, cable information, protective devices, and related electrical documentation.

It also includes fixture schedules covering lighting fixtures, ceiling fans, sockets, AC points, distribution boards, internet connection points, fire protection equipment, and lightning protection components.
