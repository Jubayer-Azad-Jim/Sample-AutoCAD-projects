# Jubayer Azad Jim — AutoCAD & Engineering Drawing Portfolio

## Featured project: 10-Storied Engineering College

This repository contains the electrical drawing documentation for a 10-storied academic building, including the original AutoCAD DWG source and plotted PDF drawing set.

**Role:** Draftsman  
**Tools:** AutoCAD, DWG, PDF

## Drawing package

The PDF set includes electrical drawing documentation such as floor-wise layouts, lighting and power plans, distribution information, fixture schedules, fire alarm and heat detector locations, lightning protection, earthing arrangements, and installation notes.
